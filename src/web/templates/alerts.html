⚙️ Konfigurace kanálů

Pro aktivaci notifikačních kanálů je třeba nastavit následující proměnné prostředí:

📧 Email
ALERTING_EMAIL_ENABLED=true
ALERTING_SMTP_SERVER=smtp.gmail.com
ALERTING_SMTP_PORT=587
ALERTING_SMTP_USERNAME=váš@email.com
ALERTING_SMTP_PASSWORD=heslo_aplikace
ALERTING_EMAIL_TO=příjemce@email.com
💬 Telegram
ALERTING_TELEGRAM_ENABLED=true
ALERTING_TELEGRAM_BOT_TOKEN=1234567890:ABCDEF...
ALERTING_TELEGRAM_CHAT_ID=-1001234567890
Bot token získáte od @BotFather, Chat ID z @userinfobot
🎮 Discord
ALERTING_DISCORD_ENABLED=true
ALERTING_DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
Webhook URL vytvoříte v nastavení Discord kanálu
📝 Poznámka: Po změně konfigurace restartujte aplikaci příkazem docker-compose restart
